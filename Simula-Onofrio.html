Come conservarlo sul telefono o sul computer

Il file è autonomo e ricorda automaticamente le scelte su questo dispositivo.

iPhone / iPad

Apri il file in Safari. Tocca Condividi e poi “Aggiungi alla schermata Home”. Se Safari non offre l’opzione per un file locale, occorre pubblicarlo su un indirizzo web privato.

Android

Apri il file con Chrome, usa il menu ⋮ e scegli “Aggiungi a schermata Home” o “Crea scorciatoia”.

Windows / Mac

Conserva Simula-Onofrio.html sul Desktop. Si apre con un doppio clic e non richiede installazione.

Simulazione storica indicativa: dati mensili di benchmark in euro, dividendi reinvestiti e costo annuo del prodotto sottratto. Non include fiscalità, spread o commissioni di negoziazione. Non costituisce consulenza finanziaria.

Salva e invia il simulatore

  1. Invia a Onofrio il solo file Simula-Onofrio.html.
  2. Onofrio lo apre con un clic: non servono altri allegati e non serve internet.
  3. Le scelte vengono memorizzate automaticamente nel browser usato.
  4. Per una vera icona installabile garantita su ogni cellulare è necessaria una pubblicazione web privata HTTPS.
